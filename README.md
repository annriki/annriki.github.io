# Ziqi Liu — Academic Homepage

Personal website: https://annriki.github.io/

Derived from [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io). The original MIT license is retained.

## Content

- `_config.yml`: profile and site settings.
- `_pages/about.md`: biography, research interests and contact details.
- `_data/navigation.yml`: section navigation.
- `images/avatar.svg`: temporary initials avatar; replace with a personal photo when available.

## Deployment

In Settings → Pages, select Deploy from a branch, main, / (root), then Save.
Google Scholar citation collection is disabled until a profile is provided.
